# Linux

## O que é

Linux é um sistema operacional de código aberto criado por Linus Torvalds em 1991.

## Principais características

- Gratuito
- Código aberto (Open Source)
- Multiusuário
- Multitarefa
- Seguro
- Estável

## Onde é utilizado

- Servidores
- Computadores pessoais
- Android
- Supercomputadores
- Sistemas embarcados

## Distribuições

- Ubuntu
- Debian
- Fedora
- Arch Linux
- Rocky Linux

## Kernel

O Kernel Linux é o núcleo do sistema operacional e controla o hardware e os recursos do computador.
