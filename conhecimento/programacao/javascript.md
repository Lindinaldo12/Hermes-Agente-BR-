# JavaScript

## O que é
JavaScript é uma linguagem de programação usada para criar sites interativos e aplicações no servidor (Node.js).

## Sintaxe Básica
- Variáveis: use 'let' para valores que mudam e 'const' para valores fixos. Evite 'var'.
- Funções: function nome() {} ou const nome = () => {}
- Condicionais: if, else, switch
- Loops: for, while

## Exemplo de Código
console.log('teste');
Este comando imprime a palavra 'teste' no console. É usado para testar e depurar códigos.

## Boas Práticas
- Sempre termine as linhas com ponto e vírgula (;).
- Use nomes de variáveis claros.
- Comente o código para explicar a lógica.
